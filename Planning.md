# Project Plan: Product Management Application

This document outlines the steps for building a product management application with a .NET backend and React frontend.

## 1. Task Breakdown (10-15 mins)

* **Backend (REST API):** C#/.NET (due to its robust API ecosystem)
* **Frontend:** React

## 2. Set Up Project (Backend) (15-30 mins)

**Goal:** Quickly set up the API and database.

* **Create .NET Web API project:**
    * `dotnet new webapi`
    * Set up controllers and models: `Product`, `ProductType`, `Colour`
    * In-memory database (Entity Framework Core or SQLite) for rapid development.
    * Install NuGet packages: `Microsoft.EntityFrameworkCore.Sqlite`, `Microsoft.EntityFrameworkCore.Tools`
    * Define `AppDbContext`.
* **Models & Database:**
    * Create data models: `Product`, `ProductType`, `Colour`
    * Establish Entity Framework Core relationships:
        * `Product` has one `ProductType` and many `Colours`.
    * Database seeding: Load data from `product-types.txt` and `colours.txt`.

## 3. API Endpoints (Backend) (30-45 mins)

**Goal:** Develop API endpoints using C#.

* **Create `ProductsController`:**
    * **Add a new product (POST):**
        * Input: `Product` payload (Name, ProductTypeId, ColourIds).
    * **Get products list (GET):**
        * Output: List of products (Id, Name).
    * **Get product details by ID (GET):**
        * Input: `id` parameter.
        * Output: Product details (Id, Name, ProductType, Colours).
* **Testing:** Test API locally using Postman or Swagger (auto-generated by .NET).

## 4. Set Up Project (Frontend) (15-30 mins)

**Goal:** Set up the basic React frontend.

* **Create React App:**
    * `npx create-react-app`
    * Install `axios` for HTTP requests.
    * (Optional) Use Material-UI for styling and form components.
* **Structure Pages/Components:**
    * **Create Product Page:**
        * Form: Product name (text), product type (dropdown), colours (multi-select).
        * `axios.post` to send payload to API.
    * **View Products List Page:**
        * Fetch data from API using `axios.get`.
        * Display data in a table: Product ID, Name, Product Type, Colours.
        * Sort by creation date.

## 5. Connect Frontend and Backend (15-30 mins)

**Goal:** Connect React frontend with .NET backend API.

* Set API base URL in a config file.
* Handle API calls in React components:
    * `POST` to add product.
    * `GET` to fetch product list.
* Test full functionality.

## 6. Sample Data Loading (10-15 mins)

**Goal:** Load data into the database.

* Data seed script: Load `product-types.txt` and `colours.txt` into respective tables.
* Automate seeding in `AppDbContext` or with a migration.

## 7. GitHub Setup & Push (10-15 mins)

**Goal:** Publish code on GitHub with clean commit history.

* Create GitHub repository.
* Push local project (backend and frontend).
* Regular commits:
    * Initial commit
    * API and DB setup
    * Add endpoints
    * Add frontend UI
    * Final fixes and tweaks

## 8. Testing & Final Adjustments (15-30 mins)

**Goal:** Ensure smooth functionality and fix bugs.

* **Manual frontend testing:**
    * Create product and verify in product list.
    * Test edge cases (missing fields, invalid data).
* **Final cleanup:**
    * Remove unused code/comments.
    * Add README with project instructions.
    * Double-check API endpoints with Postman (if needed).

## Breakdown of Time:

* Project Setup: 15-30 mins
* Backend (API) Development: 30-45 mins
* Frontend Development: 30-45 mins
* Connecting Frontend & Backend: 15-30 mins
* Sample Data Loading: 10-15 mins
* GitHub Setup & Push: 10-15 mins
* Testing & Final Adjustments: 15-30 mins
* **Total Time:** ~2-3 Hours (including breaks)
